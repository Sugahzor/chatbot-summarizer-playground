# Node.js Backend Engineer

## Must have

- 5+ years backend development experience
- Strong Node.js and TypeScript proficiency
- Express, Fastify, or NestJS in production
- REST API design and versioning
- PostgreSQL or another relational database
- Async/await and event loop fluency
- Git, code review, and CI/CD workflows

## Nice to have

- Bun or Deno runtime experience
- Prisma, Drizzle, or TypeORM
- Redis for caching or queues
- Message brokers (RabbitMQ, Kafka, SQS)
- Docker and container deployments
- Observability tooling (OpenTelemetry, Datadog, Grafana)
- WebSockets or server-sent events
- AI/LLM API integration (OpenAI, Anthropic)

## Red flags

- Frontend-only background with no server experience
- No production system experience (only tutorials or coursework)
- Frequent <1 year tenures across multiple roles
- Unfamiliar with async patterns, blocking the event loop
- No testing experience (unit, integration, or e2e)
- Cannot explain how a request flows through their stack
